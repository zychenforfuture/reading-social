# @collab/types

Shared TypeScript types for Collab Reading project.

## Installation

```bash
pnpm install @collab/types
```

## Usage

```typescript
import type { User, Document, Comment } from '@collab/types';

const user: User = {
  id: '123',
  email: 'user@example.com',
  username: 'user123',
};
```
