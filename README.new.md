# 共鸣阅读

> **评论跟着内容走，而不是跟着文档走**

一个面向阅读社群的**跨文档协同批注平台**。

上传文章、为任意段落发表评论、与他人互动点赞回复。当同一段文字出现在多篇文档中时，读者的讨论可以在内容维度聚合——而不是绑定到单一文档 URL。

---

## 🎯 为你解决这些问题

### 📚 读书笔记分散
> 你在微信读书批注了一段话，在豆瓣又看到同样的内容，想找回之前的想法，却怎么也找不到...

**共鸣阅读**：批注绑定段落内容本身，不是文档链接。无论这段文字出现在哪里，你的思考都在那里。

### 📝 文档版本混乱
> 论文改了 10 个版本，你在 v3 写的批注，在 v8 里完全看不到...

**共鸣阅读**：批注跟着内容走，文档更新时自动重映射。你的思考不会因为版本迭代而丢失。

### 💬 社群讨论割裂
> 同一篇文章被转载到 5 个群，每个群的讨论都是孤岛...

**共鸣阅读**：同一段文字的批注跨文档自动聚合。打破平台边界，让讨论真正围绕内容发生。

---

## ✨ 核心功能

| 功能 | 它能为你做什么 |
|-----|---------------|
| 📝 **内容指纹批注** | 批注绑定段落内容，不是文档链接。文档转载、版本更新，批注永不丢失。 |
| 💬 **内嵌侧边栏评论** | 仿书阅读体验，正文与评论并排显示，不遮挡任何内容。 |
| 🌐 **跨文档评论聚合** | 同一段文字出现在多篇文档中？所有讨论自动汇聚一处。 |
| ⚡ **大文档秒开** | 百万字级文档也能流畅阅读，异步分块处理，章节快速定位。 |
| 🎨 **个性化阅读设置** | 字号、行距、背景主题自由调节，打造专属阅读体验。 |
| 🔔 **实时通知中心** | 评论回复、点赞互动实时推送，不错过任何精彩讨论。 |

## 🛠️ 技术栈

- **前端**：React 19 + TypeScript + Vite + Tailwind CSS
- **后端**：Node.js + Express + PostgreSQL + Redis
- **向量检索**：Qdrant + 语义嵌入模型
- **部署**：Docker Compose
