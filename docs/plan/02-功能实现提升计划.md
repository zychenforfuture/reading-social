# 功能实现提升计划

## 1. 目标
- 补齐核心产品能力，优先完善跨文档评论体验
- 提升 Mobile 与 Web 功能一致性
- 建立功能交付优先级机制，避免功能碎片化

## 2. 现状问题
- 跨文档评论后端能力已有基础，但前端聚合视图不足
- Mobile 端通知中心与阅读设置未完全补齐
- 向量检索能力存在基础设施，但用户可见功能不足

## 3. 行动项
- 短期（1-3 周）
  - 明确产品优先级：跨文档评论聚合 > Mobile 补齐 > 语义检索体验
  - 定义跨文档评论聚合页面信息架构和交互流程
  - 补齐 Mobile 通知中心和阅读设置基础功能
- 中期（4-8 周）
  - 上线跨文档评论聚合页（按相似片段聚合评论）
  - 新增语义搜索入口（基于 Qdrant 检索）
  - 增加文档处理状态可视化（排队、处理中、可读）
- 长期（8-12 周）
  - 支持多格式文档导入（PDF/EPUB 优先）
  - 打通检索 -> 跳转阅读片段 -> 发表评论完整链路

## 4. 里程碑与验收
- M1：跨文档聚合交互稿和 API 契约冻结
- M2：Web 端跨文档聚合 MVP 上线
- M3：Mobile 功能对齐 Web 核心闭环
- 验收指标：
  - 评论二次互动率提升 20%
  - Mobile 端主流程完成率达到 Web 的 90%+
