# 运维文档索引

本目录用于沉淀发布、值班、故障排查与复盘流程文档。

## 模板与流程
- [TEMPLATE.md](./TEMPLATE.md)：通用运维文档模板
- [发布清单.md](./发布清单.md)：发布前检查、发布执行、发布后验证与回滚
- [值班手册模板.md](./值班手册模板.md)：值班安排、巡检、告警处理、交接模板
- [事故复盘模板.md](./事故复盘模板.md)：事故时间线、根因分析、行动项跟踪

## 使用建议
1. 发布前先使用发布清单逐项打勾确认。
2. 值班期间按值班手册模板记录巡检和事件处置。
3. 事故恢复后 24 小时内完成复盘文档并明确行动项负责人。
