# Runbook：数据库连接故障排查

## 1. 背景
- 适用场景：API 或 Worker 无法连接 PostgreSQL（超时、认证失败、连接拒绝）
- 影响范围：登录、文档读取、评论写入、通知查询

## 2. 前置条件
- 已具备本机或服务器 Docker 与数据库访问权限
- 已确认环境变量文件可读（.env 或 .env.production）

## 3. 排查步骤
1. 检查容器状态

```bash
./scripts/dev.sh status
# 或
./scripts/deploy.sh status
```

2. 检查数据库健康状态

```bash
docker exec collab-postgres pg_isready -U admin -d collab_comments
```

3. 检查连接串与密码是否一致

```bash
echo "$DATABASE_URL"
echo "$DB_PASSWORD"
```

4. 校验数据库用户密码（开发环境）

```bash
./scripts/dev.sh infra
```

5. 查看数据库日志

```bash
./scripts/dev.sh logs
# 生产环境
docker compose -f docker-compose.prod.yml --env-file .env.production logs -f postgres
```

## 4. 快速修复
- 连接拒绝：确认 5432 端口未被占用，容器已启动
- 认证失败：重新对齐 DB_PASSWORD 与 DATABASE_URL
- 表缺失：执行初始化 SQL

```bash
docker exec -i collab-postgres psql -U admin -d collab_comments < docker/postgres/init.sql
```

## 5. 验证步骤

```bash
curl -s http://localhost:3000/health
pnpm --filter @collab/api test -- auth.test.ts
```

预期：健康检查返回 ok，相关测试通过。

## 6. 回滚方案
- 回滚到上一版环境变量
- 恢复最近数据库备份
- 若生产不可用，先切换只读模式并暂停写入
